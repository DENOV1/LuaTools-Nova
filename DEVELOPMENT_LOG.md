# DEVELOPMENT_LOG — LuaTools Nova (v1.0.1 audit)

## Session 2 — 2026-11-16 (engineering audit & release)

1. **Recovery.** Sandbox recycled again; toolchain + repo restored (SDK reinstall; repo cloned from the GitHub remote — the recycle insurance pattern paid off exactly as designed).
2. **Startup crash investigation.** Reproduced the reported `InvalidOperationException` for `UnlockerServiceProxy` from the report's stack trace. Mapped the entire `Get<T>` call surface (`grep -rn "svc.Get<"`) — found **14+ further latent crashes** behind the first one (MainWindow's 9 page-VM resolutions, plugin-backend facade VM resolutions, HomeViewModel's plugin-service fetch).
3. **Architectural fix.** `NovaServices` became the single composition root: registers all domain services + proxies + integrations + `ILoggerFactory`/`ILogger<>` + **all 12 ViewModels**; accepts a `configure(IServiceCollection)` callback used by the UI layer (and tests) to contribute boundary implementations before Build; builds with **ValidateOnBuild + ValidateScopes**. `ModeViewModel`/`HomeViewModel` moved to constructor injection. `NovaServices` made `IDisposable`.
4. **DI audit.** 10 new tests in `DiAuditTests`: full-resolution audit of every registered service and interface; all-VM resolution regression; singleton semantics (incl. shared `DropInstallViewModel`); proxy↔settings wiring; and a test proving `ValidateOnBuild` now throws at container-build time for a missing dependency (with the same descriptor shape as the original crash).
5. **Headless UI lifecycle.** Standing up real UI tests required solving Avalonia's headless API surface: correct attribute set (`[assembly: AvaloniaTestApplication]` + `[AvaloniaFact]` from Avalonia.Headless/.XUnit), `UseSkia()` + `UseHeadlessDrawing=false` (stub drawing cannot create glyph typefaces for FluentAvalonia's embedded `Symbols` font — diagnosed via FontManager probe inside the session thread), and a session-scoped MainWindow (matches real app lifetime; avoids cross-container races in fire-and-forget page loads). Result: 5 tests that construct the real `MainWindow` through compiled XAML from the production container, assert all 10 page DataContexts, navigate all 9 pages, Show/Close.
6. **Bugs found & fixed along the way.** `IToastPresenter` interface segregation (MainWindow hard-cast); `install.sh` Exec-path rewrite + applications-dir creation for user-local installs; `publish.sh` SDK path autodetection.
7. **Release engineering.** Clean Release build via `packaging/publish.sh` (tests first); 99 MB self-contained linux-x64 bundle; ELF + exec-permission + staged assets verified; native smoke test reaches `XOpenDisplay` (no display in sandbox). Packaging scripts executed end-to-end (user-local, no sudo): install → verify files/desktop-entry/icons → uninstall → verify removal + user-data preservation.
8. **Release.** Tag `v1.0.1` pushed to the audited commit; CI (ubuntu-latest) build+test+publish verified; GitHub Release "LuaTools Nova v1.0.1" created as **pre-release** (GUI-on-real-display not verified) with tar.gz + SHA256SUMS.
